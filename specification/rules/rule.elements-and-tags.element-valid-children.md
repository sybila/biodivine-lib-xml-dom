# Rule: Element valid with children content model

When an element type is declared with a children content model, the sequence of child elements must belong to the language generated by the regular expression in the content model.

## Rationale

> Validity constraint: Element Valid — The declaration matches children and the sequence of child elements belongs to the language generated by the regular expression in the content model, with optional white space, comments and PIs between the start-tag and the first child element, between child elements, or between the last child element and the end-tag.
> — §3.1 Start-Tags, End-Tags, and Empty-Element Tags

## Valid Example

```xml
<?xml version="1.0"?>
<!DOCTYPE root [
  <!ELEMENT root (head, body)>
  <!ELEMENT head (#PCDATA)>
  <!ELEMENT body (#PCDATA)>
]>
<root><head>Title</head><body>Content</body></root>
```

## Violating Example

```xml
<?xml version="1.0"?>
<!DOCTYPE root [
  <!ELEMENT root (head, body)>
  <!ELEMENT head (#PCDATA)>
  <!ELEMENT body (#PCDATA)>
]>
<root><body>Content</body><head>Title</head></root>
```
