# Rule: Encoding names SHOULD be matched case-insensitively

XML processors SHOULD match character encoding names in a case-insensitive way.

## Rationale

> XML processors SHOULD match character encoding names in a case-insensitive way. (§4.3.3)

## Note

> This is a SHOULD (not MUST) constraint. A processor that matches encoding names case-sensitively is still conformant, but case-insensitive matching improves interoperability.
