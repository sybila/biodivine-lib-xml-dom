# Rule: Parameter entities are well-formed by definition

All external parameter entities are well-formed by definition. All internal parameter entities are well-formed by definition.

## Rationale

> All external parameter entities are well-formed by definition. All internal parameter entities are well-formed by definition. (§4.3.2)

## Note

> Unlike general entities, parameter entities have no well-formedness constraint on their replacement text matching the content production. This is because parameter entities are expanded in the DTD context where the grammar is different.
